AVIPACHITO PWA starter

Sube estos archivos a un hosting HTTPS estático (por ejemplo GitHub Pages). Abre la URL en Chrome Android, y elige menú ⋮ > Instalar aplicación / Añadir a pantalla principal.
El botón Ingresa al sistema abre el Google Apps Script publicado que proporcionó el usuario. Esta PWA es un lanzador móvil; el sistema de ventas se ejecuta en Apps Script y requiere Internet.
